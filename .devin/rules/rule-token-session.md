---
description: トークン削減。1つのセッションを、その issue の話題に保つ(範囲外の質問に答えない)
trigger: always_on
---

issue を実装するセッション(PR の作成・修正を含む)では、次のルールに従う。

1. 答えてよいのは、その issue の内容、完了条件、検証、レビュー指摘、PR の修正理由に関すること
2. それ以外の質問には答えない。「この質問は、この PR と関係がないため、新しいセッションでお願いします」とだけ返す
3. 範囲内かどうか迷うときは、答える
4. 範囲内かどうかは、会話にある内容だけで判断する。判断のために、PR や issue を読みに行かない
