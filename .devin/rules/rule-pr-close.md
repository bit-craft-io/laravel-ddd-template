---
description: PR が閉じたら、セッションをアーカイブする
trigger: always_on
---

このセッションで作った PR が閉じた(マージ、またはマージせずにクローズ)と知らされたときは、次のルールに従う。

1. 次のどれかに当てはまるときは、アーカイブしない
      - このセッションで作った PR に、まだ開いているものがある
      - 人からの依頼で、まだ終わっていないものがある
      - PR が閉じた後に、人が別の作業を頼んでいる
2. 当てはまらないときは、Slack のスレッドに「PR #<番号> が閉じたため、このセッションをアーカイブします」と報告してから、このセッションをアーカイブする
3. アーカイブの前に、メモリやナレッジに残すことがあれば、先に残す
4. 人が「アーカイブしない」「確認のみ」と言っているときは、アーカイブしない
