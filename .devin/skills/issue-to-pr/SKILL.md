# issue-to-pr

- 説明: Slackで渡されたissueを読み、実装してPRを作る

## 内容

Slackで渡されたissueを実装し、PRを作成する。
ブランチ名・PR本文・作業の進め方は、組織のルールに従う。

## 手順
1. メッセージ内のissueと指示を読み、内容を把握する
2. 不明点があればSlackスレッドで質問し、回答を待つ
3. ブランチを作成して実装する
4. テストを実行して動作を確認する
5. PRを作成し、変更内容と確認結果をSlackスレッドに報告する

## 仕様
- issueの受け入れ条件を満たしていること
- 既存のテストが壊れていないこと

## 禁止事項
- mainブランチへ直接pushしない
- issueに書かれていない範囲の変更をしない
